📈 Upgrade Investara Stock Platform

A modern stock analytics and investment platform designed to help users track market trends, analyze stock performance, and make smarter investment decisions through interactive dashboards and real-time insights.

🚀 Overview

Upgrade Investara Stock Platform is a full-stack fintech application focused on providing:

📊 Real-time stock market insights
📈 Interactive charts & analytics
⭐ Smart watchlists
📰 Financial news integration
💼 Portfolio monitoring
🔍 Stock trend visualization
⚡ Fast and responsive UI

The platform is built to simplify stock market analysis for both beginners and experienced investors.

⚙️ Installation
1️⃣ Clone the Repository
git clone https://github.com/AnshTiwari07/Upgrade_Investara_Stock_Platform.git
2️⃣ Navigate to Project Directory
cd Upgrade_Investara_Stock_Platform
3️⃣ Install Dependencies
npm install

or

pnpm install
▶️ Run the Application
Start Frontend
npm run dev
Start Backend
npm start
🌐 Environment Variables

Create a .env file in the root directory and add:

PORT=5000
MONGO_URI=your_mongodb_connection
API_KEY=your_stock_api_key
🐳 Docker Setup
Build and Run
docker-compose up --build
